# tgbot — код бота (бывший app.py)

`app.py` в корне остался точкой входа (`python app.py`), а сам код разнесён по модулям.
Логика не менялась: функции перенесены как есть.

| Модуль | Что внутри |
|---|---|
| `config.py` | переменные окружения, пользователи, имена, клиенты Telegram и Gemini |
| `webserver.py` | HTTP-сервер: /health, /draw, /pet, /pet-garden/*, API игры, загрузка рисунков, сборка страниц из частей |
| `db.py` | пул подключений PostgreSQL, таблицы, история сообщений |
| `memory.py` | память бота (факты, важность, затухание, удаление) |
| `utils.py` | доступ, время, длинные сообщения, Markdown → HTML |
| `weather.py` | погода и геокодинг |
| `llm.py` | Gemini: каскад моделей, учёт квоты, голос, извлечение фактов |
| `reminders.py` | напоминания: разбор текста, база, расписание |
| `handlers.py` | /start, /pet, /draw, /memory… и главный обработчик сообщений |
| `commands_extra.py` | /remind, /reminders, /reminddelete, /limits, /weather |
| `inline_mode.py` | инлайн-режим |
| `main.py` | фоновые циклы, меню команд, запуск polling |

**Порядок регистрации обработчиков важен** (aiogram проверяет их по очереди).
Он задаётся импортом в `main.py`: `handlers` → `commands_extra` → `inline_mode` — так же, как было в app.py.
