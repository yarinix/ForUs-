# pet_data — данные игры

Каталог разбит по категориям; `pet.py` собирает его обратно в `CATALOG` (порядок прежний).

| Файл | Что внутри |
|---|---|
| `food.py` | еда (`FOOD`) |
| `clothes.py` | редкость, слоты, конфликты слотов, одежда (`WEAR`) |
| `furniture.py` | мебель (`FURNITURE`) и стандартная расстановка (`STD_PLACE`) |
| `texts.py` | реплики выдры (`SAY`) и тексты отказов (`REFUSE`) |

Чтобы добавить вещь — допиши её в нужный файл. Рисунок кладётся в клиент под тем же id
(`static/pet/js/clothes/` или `static/pet/js/furniture/`).
