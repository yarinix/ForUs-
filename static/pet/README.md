# Игра «Наша выдра» — клиент

Раньше всё лежало в одном `static/pet.html` (3300+ строк). Теперь код разложен по папкам.
Сервер (`tgbot/webserver.py → build_page`) собирает страницу на лету: каждая строка
`// @include путь` или `/* @include путь */` в `index.html` заменяется содержимым файла.
Собранная страница **побайтно совпадает** со старым `pet.html` и кэшируется,
пока какой-нибудь файл не изменится.

Все JS-файлы — части одной общей функции, поэтому переменные видны между файлами,
как и раньше. **Порядок `@include` в index.html важен** — не переставляй строки.

## Как добавить новый файл
1. Создай файл, например `js/furniture/actions.js`.
2. Добавь строку `  // @include js/furniture/actions.js` в `index.html` — после файлов, от которых он зависит.
3. Перезапуск сервера не нужен: изменения подхватятся при следующем открытии игры.
